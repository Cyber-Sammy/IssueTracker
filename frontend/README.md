# Issue Tracker Frontend

Учебный интерфейс трекера задач, созданный на React и JavaScript с помощью Vite.

## Запуск проекта

```bash
npm install
npm run dev
```

## Доступные команды

- `npm run dev` — запустить локальный сервер разработки.
- `npm run build` — собрать production-версию проекта.
- `npm run lint` — проверить JavaScript-код линтером.
- `npm run preview` — локально открыть собранную production-версию.
